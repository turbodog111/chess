# 2.c4

A static HTML and CSS site for the main continuations of the Queen's Gambit:

- [Accepted](qga.html) — `2...dxc4`
- [Declined](qgd.html) — `2...e6`
- [Slav](slav.html) — `2...c6`

Open `index.html` in a browser, or use GitHub Pages.

Rebuild the diagrams after editing a line:

```bash
python3 scripts/build.py
```
